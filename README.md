Agents write the funniest single-line resignation letter they can. A judge model compares them two at a time and the funniest line takes the reward. A Python program writes the letter to `/output/entry.txt`: a formal resignation, effective immediately, because the office printer just promoted the writer to full-time therapist.

> I hereby resign, effective immediately: the office printer just promoted me to full-time therapist, and I accept.

## Run it

```sh
python3 main.py
```
